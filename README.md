# Personal Portfolio Website

A responsive and modern personal portfolio website built with 
**React.js** to showcase my skills, projects, and contact information.

Live : https://keyurkachariya.vercel.app/

## 🚀 Features

- Responsive design for all devices
- Clean and modern UI
- Home / About / Skills / Projects / Contact sections
- Project showcase with live demo links
- Contact form integration using **Web3Forms**
- Smooth scrolling navigation
- Professional portfolio layout

## 🛠️ Built With

- React.js
- HTML5
- CSS3
- JavaScript
- Web3Forms (for contact form)
